# Cube-Climb
Unity project of a cube platformer game

A 2D vertical-climbing platformer built in Unity where players jump between platforms, stick to walls, collect coins, and avoid enemies.

## Prerequisites

* **Unity Hub** installed ([Download Unity Hub](https://unity.com/download))
* **Unity Editor** version 6000.6.0f1
* **Git** installed ([Download Git](https://git-scm.com/downloads))

## How to Clone and Run

1. **Clone the repository**
   Open a terminal or command prompt and run:
   ```bash
   git clone https://github.com/Clxudbxy/Cube-Climb.git

2. Launch Unity Hub.

3. Click Add (or Add project from disk) in the top-right corner.

4. Navigate to and select the cloned Cube-Climb folder (the root folder containing Assets, Packages, and ProjectSettings).

5. Click the project in Unity Hub to open it in the Unity Editor. (First-time opening may take a few minutes while Unity imports assets and generates the Library folder.)

6. Open the main game scene

7. In the Unity Editor's Project window at the bottom, open the Assets/Scenes folder.

8. Double-click Level 1 to load the level.

9. Click the Play button (▶) at the top center of the Unity Editor.

Controls:
Move left: A / left arrow, 
Move right: D / right arrow, 
Jump / wall release: Spacebar
