# Cube-Climb
Unity project of a cube platformer game

A 2D vertical-climbing platformer built in Unity where players jump between platforms, stick to walls, collect coins, and avoid enemies.

## Prerequisites

* **Unity Hub** installed ([Download Unity Hub](https://unity.com/download))
* **Unity Editor** version **[e.g., 6000.0.23f1]** (check `ProjectSettings/ProjectVersion.txt` for the exact version)
* **Git** installed ([Download Git](https://git-scm.com/downloads))

## How to Clone and Run

1. **Clone the repository**
   Open a terminal or command prompt and run:
   ```bash
   git clone [https://github.com/](https://github.com/)[YOUR-USERNAME]/[YOUR-REPO-NAME].git
   Open the project in Unity Hub

Launch Unity Hub.

Click Add (or Add project from disk) in the top-right corner.

Navigate to and select the cloned [YOUR-REPO-NAME] folder (the root folder containing Assets, Packages, and ProjectSettings).

Click the project in Unity Hub to open it in the Unity Editor. (First-time opening may take a few minutes while Unity imports assets and generates the Library folder.)

Open the main game scene

In the Unity Editor's Project window at the bottom, open the Assets/Scenes folder.

Double-click [Your Main Scene Name, e.g., SampleScene] to load the level.

Start the game

Click the Play button (▶) at the top center of the Unity Editor.

Controls:
Move left                    A / left arrow
Move right                   D / right arrow
Jump / wall release          Space
